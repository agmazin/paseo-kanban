## Установка и обновление

Как у Диалогов: основной Paseo грузит плагин из клона по тегу, а не из этого каталога.

```sh
git clone --branch v0.1.2 /Users/agmazin/Yandex.Disk.localized/public/projects/local/paseo-kanban /Users/agmazin/Library/Developer/paseo-releases/paseo-kanban
ln -s /Users/agmazin/Library/Developer/paseo-kanban/node_modules /Users/agmazin/Library/Developer/paseo-releases/paseo-kanban/node_modules
paseo plugin install /Users/agmazin/Library/Developer/paseo-releases/paseo-kanban
```

Обновление: `git -C /Users/agmazin/Library/Developer/paseo-releases/paseo-kanban fetch --tags && git -C ... checkout vX.Y.Z`,
затем `paseo plugin reload paseo-kanban`. Откат - тот же checkout на прежний тег. Отключить - `paseo plugin disable paseo-kanban`.
Зависимости - вне Яндекс.Диска, `node_modules` - симлинк на `/Users/agmazin/Library/Developer/paseo-kanban/node_modules`.
Проверка: `npm run typecheck`, `npm test`.

- общий канбан - панель рабочего пространства (`addWorkspacePanel`, вкладка рядом с чатами) и кнопка

  заводит карточку; карточку агент заводит инструментом, который плагин добавляет агентам (`server.before`, MCP);
