# Paseo "Канбан"

Плагин Paseo: канбан задач по проектам (рабочим пространствам) прямо в Paseo, чтобы уйти с досок Multica.

Состояние на 21.10.2026: только макеты, ждут одобрения Александра. Код и установка - после одобрения,
отдельным плагином (Диалоги и Лимиты не трогаем). Задание - `docs/source/2026-10-21-task.md`.

- `prototype/live.html` - живой макет v2 (по замечаниям Александра 21.10.2026, эталон - его доска TickTick): колонки без своих рамок, компактные карточки - только содержательный заголовок, исполнитель и время, без плашек и подсветок; сортировка как в TickTick (кнопка со стрелками: Произвольно, Дата изменения, Дата создания, Название, Чат, Исполнитель; по возрастанию или убыванию; "Произвольно" - порядок перетаскиванием внутри колонки), меню "..." - Скрыть готовые, Показать детали. v3 (21.10.2026): архив свёрнут отдельной группой "Архив" внизу каждой колонки, как "Выполнено" в TickTick (при группировке по агенту или исполнителю - отдельная колонка "Архивные чаты"); "Группировать по" задаёт колонки: Статус, Агент (чат), Исполнитель, Нейросеть, Дата изменения; внутри колонок подгруппы по полю сортировки (Статус, Агент, Исполнитель). v4 (21.10.2026): вариант А утверждён (у карточки свой исполнитель-подагент); сортировка и порядок меняют только карточки внутри колонок, колонки не трогают; карточка: дата серым слева вверху, заголовок, внизу логотип нейросети и имя агента-чата, в самом низу стрелкой исполнитель со своим логотипом, мельче и серее; цветные точки статусов в заголовках колонок и групп, а на карточке - только когда колонки не по статусу. Колонки: Очередь, В работе, Нужен ответ, Ждёт приёмки, Готово. Вопрос, приёмка (Принять/Вернуть) и ответ - в карточке по клику.
- `prototype/v1.html` - статичные экраны; `prototype/shots/` - их снимки для показа в чате.
- Перерисовать снимки: headless Chrome по `prototype/v1.html` (каждый экран - блок `.shot`).

Что позволяет Paseo 0.12 (проверено по справочнику плагинов):
- общий канбан - панель рабочего пространства (`addWorkspacePanel`, вкладка рядом с чатами) и кнопка
  в шапке пространства (`addHeaderButton`); закрепить вкладку первой плагин не может, порядком вкладок владеет Paseo;
- канбан чата - панель агента в правой боковой панели (`locations: ["explorer"]`, рядом с "Файлы" и "Изменения");
- открыть её может сам плагин (`client.openPanel(id, { workspaceId, agentId, location: "explorer" })`), когда агент
  заводит карточку; карточку агент заводит инструментом, который плагин добавляет агентам (`server.before`, MCP);
- агенты и архив читаются через SDK, как в Диалогах.
